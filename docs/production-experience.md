# 第五轮：声音、后期与生产体验

本轮继续使用原有五章结构、电影式滚动、真实曲面花朵和六主题 Color Lab。工程沿用 Next.js 16.4.1、React 19.2、React Three Fiber、Three.js、Drei、GSAP 和 Zustand，没有新增运行时依赖。本文记录实现与验收方法，不替代最终测试日志或真实设备性能记录。Vercel 配置已准备，尚未部署；操作步骤见[部署指南](../DEPLOYMENT.md)。

## 可选声音

页面初始为 `SOUND OFF`。创建控制器、渲染面板和建立订阅均不会创建 AudioContext 或请求配乐。点击 SOUND 后，AudioController 在原始用户手势的调用栈内创建 / 恢复上下文，再异步取得音轨并解码。内置音轨按循环播放，音量默认 55%，可调为 0–100%。

声音面板具有播放 / 暂停、音量、低中高频仪表、本地文件入口与可读错误提示。按钮、滑块和文件输入可用键盘操作，Escape 收起面板并恢复焦点。页面隐藏时暂停并保存播放位置，返回后不会自动发声；需要再次主动播放。浏览器或设备中断音频时同样保留主动恢复入口。

内置 `BLOOM — Study No. 1` 使用纯数学振荡器、平滑和弦包络、柔和低频脉冲和高频泛音生成，无外部样本或录音。文件为 32 秒、22050 Hz、单声道 16-bit PCM WAV，大小 1,411,244 字节，约 1.4 MB。源码在 `scripts/generate-score.mjs`，运行 `npm run audio:generate` 可以确定性重建；授权为 [CC0](../public/audio/LICENSE.md)。生成脚本会校验 WAV 头、时长、峰值、RMS 和首尾采样衔接。

选择本地音频时，File 的内容只在当前浏览器内读取和解码，不上传、不创建服务器文件，也不依赖远程音频地址。输入限制为：压缩 / 原始文件最多 12 MiB，时长最多 120 秒，最多双声道，采样率不超过 96 kHz，解码 PCM 内存最多 48 MiB。支持的实际编解码格式取决于浏览器；无效、过大或无法解码的文件显示错误并提供重试。切换音源时通过代次标记取消旧请求和过时的异步解码结果。

## 音频状态与视觉映射

| 模块 | 职责 |
| --- | --- |
| `AudioController` | 用户手势启动，音源、增益、Analyser、缓存、暂停偏移、请求取消和生命周期 |
| `AudioSignal` | 固定 TypedArray、频段能量、去 DC 的 RMS、平滑与归零 |
| `AudioProvider` | 每个体验一个控制器；只有播放或平滑衰减时挂载一个 GSAP ticker |
| `AudioDock` | 离散播放状态用订阅更新，频段仪表直接更新持久 DOM 节点 |

分析使用 2048 点 FFT。低频为 20–180 Hz，中频为 180–2200 Hz，高频为 2200–9000 Hz；RMS 来自波形。四个输出限制在 `[0, 1]`，使用约 0.04 秒 attack、0.25 秒 release 的指数跟随器，避免闪烁与突变。分析缓冲与输出 frame 持续复用，声音分析不会逐帧更新 React 或 Zustand。

| 输入 | 有界视觉响应 |
| --- | --- |
| 低频 | 花朵整体缩放最多增加约 2.6%，主光强度最多增加约 16%，花心能量轻微增强 |
| 中频 | 花瓣缓慢摆动，旋转幅度约 0.022 rad；roughness 最多降低 0.025，保留下限 |
| 高频 | 微粒闪动与花瓣约 0.0035 rad 的微振动 |
| RMS | 花心发光的整体呼吸包络 |

滚动 `CinematicRuntime`、主题 `ThemeController` 与声音 `AudioController` 分别持有状态。场景在现有姿态上叠加小幅音频响应；音频不重置五章节进度、镜头、主题或局部交互。暂停、静音或结束后信号平滑归零。`prefers-reduced-motion` 下关闭音频造成的场景变化，用户仍可主动收听和调整音量。

## 真实轻量后期

`CinematicEffects` 仅在桌面、精细指针、高质量档且未启用减少动态效果时挂载。没有使用 CSS filter 模拟景深或发光，也没有引入额外后期库。

第一 pass 将原场景写入 HalfFloat HDR RenderTarget，带真实 DepthTexture，分辨率为物理绘制缓冲的 85%。第二 pass 使用一个屏幕 Shader：按场景深度和花心焦距计算 9-tap 离焦采样，保留约 1.1 倍花朵尺度的焦内区，半径最多 2 个物理像素；8-tap 高光模糊只提取强度超过 1.1 的 HDR 高光，Bloom 强度限制在 0.12–0.18。

主场景保持线性 HDR，最终合成一次完成 tone mapping 和输出颜色转换。Shader 保留 alpha，并处理预乘覆盖率，让透明 Canvas 下的 CSS 氛围继续显示；DOM 标题、导航与声音面板不受后期处理。景深保持轻微，避免破坏花瓣与 3D 章节文字的可读性。

高质量渲染用 `useFrame` priority 1 接管场景绘制，正常路径为场景 RT + 屏幕合成两 pass。初始化、浮点缓冲支持、Framebuffer 或 Shader 失败时立即直接渲染原场景，并通知场景关闭后期、降至 BALANCED。renderer 的渲染目标、viewport、scissor、清屏、统计与 Shader 错误处理状态在 `finally` 中恢复；关闭和卸载时释放自建目标、深度纹理、屏幕 Geometry 与 ShaderMaterial。

`ScenePreparation` 在轮廓加载阶段用 `compileAsync` 预热普通、透射、幻彩、透射幻彩及透射背面的程序，并覆盖线性 RT 与屏幕输出。用于预热的代理借用现有曲面、从不加入可见场景；保留一个有限的材质池使 Three.js 的程序缓存持续可用，卸载时释放。章节字形纹理同时提前上传。准备完成后才发布 READY，帧预算不会把准备期间的编译开销当作持续低帧率。

可选后期故障会锁定 BALANCED 上限，避免健康帧预算重新提升到 HIGH；已知失败的绘制通道清理其 GL 错误队列后重新绘制原场景。普通路径不会逐帧查询或吞掉 GL 错误。实际整段滚动仍可能出现浏览器或驱动长帧，不能由预热推断恒定帧率。

## 质量预算

设备约束来自窄屏或 coarse pointer，因此触摸平板也关闭后期并降低几何细节。ECO 可主动进入低质量，退出 ECO 后回到自动预算已有的档位；自动预算只降档，不在相邻档位间反复切换。

手机声音和 Color Lab 使用独立的 44 px 操作目标与互斥抽屉；展开时收起遮挡的雕刻控制。终章进度达到 0.94 后隐藏旧雕刻控制条，为页脚和 Replay 留出空间，花朵拖动表面、声音和主题仍可用；向前面章节滚动会恢复控制条。

| 档位 | DPR 上限 | 花瓣 | 悬浮微粒 | 透射 | Bloom / DOF |
| --- | --- | --- | --- | --- | --- |
| 桌面 HIGH | 1.5 | 42 | 56 | 按主题 | 开启 |
| 桌面 BALANCED | 1.2 | 42 | 42 | 按主题 | 关闭 |
| 手机 / 触摸平板 BALANCED | 1.15 | 27 | 18 | 0 | 关闭 |
| 桌面 ECO | 1.0 | 27 | 10 | 0 | 关闭 |
| 手机 / 触摸平板 ECO | 0.85 | 27 | 10 | 0 | 关闭 |

低细节三层曲面分别共享 Geometry，使用 22 × 8 分段；普通桌面为 34 × 14。花粉用实例化网格。两份物理花瓣材质持续复用；低细节模式将 transmission 设为 0，保留主题色、清漆和形体。粒子数变更只发生在质量切换时，不逐帧重建。

FrameBudget 先预热 2 秒，再累计 1.5 秒窗口；连续两个慢窗口才降一档。HIGH 的判断阈值约为 42 fps，BALANCED 为桌面 29 fps / 约束设备 27 fps。这些是自适应触发阈值，不是性能承诺，也不代表已在特定设备测得这些帧率。超过 0.25 秒的中断帧清空窗口，避免把标签切换当成连续负载。

Canvas 沿用 `frameloop="demand"`，只在活跃动画时继续请求帧，隐藏时停止持续绘制。反射环境仅生成一帧；后期没有每帧分配新 Geometry、Material、向量或 RenderTarget，改变窗口大小仅调整目标尺寸。

## 生命周期与失败恢复

音频暂停会停止并断开一次性 BufferSource、保存偏移和停止持续分析。卸载时取消 fetch、废弃过时解码、断开 source / gain / analyser、移除状态和可见性监听、清除订阅并关闭上下文。Provider 使用持有计数处理 StrictMode effect 重放，防止开发模式短暂清理提前销毁仍被使用的控制器。

场景保留前轮错误边界、WebGL2 能力检测和二维轮廓回退。音频不可用或播放失败时，五章内容、导航、颜色与花朵控制继续可用；后期失败时回退原始渲染。组件卸载或质量变化时释放自己拥有的几何体、材质、纹理及渲染目标，避免将旧资源留在 GPU。

## 手动验收

以下是待执行或重复验收的清单，不表示已全部通过。桌面 Edge 可用；iOS 真机、Android 真机和 Safari 尚未验证，必须单独记录。

1. 运行 lint、类型检查、单元测试和生产构建，保存实际输出，再以生产服务器打开首页。
2. 初次进入不操作 SOUND，确认静音、无配乐请求，五章滚动、章节菜单、锚点、Replay 与 Color Lab 正常。
3. 拖动旋转，点击 / 长按花心，调节 UNFOLD / GLOW，切换四种快捷材质和六主题，确认局部操作后仍可继续章节叙事。
4. 点击 SOUND，确认加载后循环播放；调整音量、暂停、继续，观察频段仪表、细微呼吸和花瓣响应。播放前后的章节位置与镜头保持一致。
5. 载入一段符合限制的本地音频；确认网络中没有文件上传。再尝试过大、损坏、过长的音频，检查错误提示和重试；快速切换或暂停时旧请求不得恢复播放。
6. 隐藏标签页再返回，确认声音保持暂停；重新点击后才恢复。反复开关声音不应出现重叠声部。
7. 桌面 HIGH 检查花心高光与轻微景深、透明背景和 3D 文字；切换 ECO 后画面与导航仍完整。观察实际档位和资源数，不预设固定 FPS。
8. 在手机 / 触摸平板检查单指拖动、页面滚动、声音与 Color Lab 布局；高质量后期应关闭，透射为 0。
9. 启用减少动态效果，检查静态叙事与按钮可用、声音可主动播放，但没有音频驱动的场景运动；禁用 WebGL 时验证二维回退和全部五章内容。
10. 观察控制台、网络错误和 GPU 资源诊断；重播、切换质量、缩放窗口及离开页面后，不应持续增加资源或留下声音。

本机实际执行结果见[第五轮验收记录](verification-round5.md)，其中明确浏览器、通过项目、资源变化和未覆盖设备。部署前在 Preview 上重新执行同一清单。
